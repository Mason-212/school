## Page 1 — P.2 Exponents, Roots, Radicals

![Page 1](Ch.%20P_images/page-01.png)

### P.2 Exponents

**Rules**

- $x^2 \cdot x^4 = x^6$ (add)
- $(x^2)^4 = x^8$ (multiply)
- $\dfrac{x^{10}}{x^7} = x^3$ (subtract)
- $x^0 = 1$

**Examples**

- $2^{-3} = \dfrac{1}{2^3} = \dfrac{1}{8}$
- $\dfrac{1}{3x^{-2}} = \dfrac{x^2}{3}$
- $(-4x^2)^{-2} = \dfrac{1}{(-4x^2)^2} = \dfrac{1}{16x^4}$
- $\left(\dfrac{5}{4}\right)^{-2} = \left(\dfrac{4}{5}\right)^2 = \dfrac{16}{25}$

**Larger products / scientific notation**

- Circled results include $\dfrac{24x^7}{y^2}$ and $\dfrac{16z^8}{x^{23}y^{16}}$
- $8.21 \cdot 10^7 = 82{,}100{,}000$
- $8.21 \cdot 10^{-3} = 0.00821$
- $(3.2 \cdot 10^2)(2.4 \cdot 10^5) = 7.68 \cdot 10^7 = 76{,}800{,}000$
- $\dfrac{8.21 \cdot 10^5}{3.7 \cdot 10^{-5}} = 2.219 \cdot 10^{10}$
- $(5.7 \cdot 10^{-3})^2 = 32.49 \cdot 10^{-6} = 3.249 \cdot 10^{-5}$
- Note: “key between 0 & 10”

### Roots

- $\sqrt{16} = 4$, $-\sqrt{16} = -4$
- $x^2 = 16 \Rightarrow x = \pm 4$
- $\sqrt{75} = \sqrt{25 \cdot 3} = 5\sqrt{3}$
- $\sqrt{1080} = 6\sqrt{30}$
- $\sqrt{64x^4y^3} = 8x^2y\sqrt{y}$
- $\sqrt[4]{32x^8y^9z^{10}} = 2x^2y^2z^2\sqrt[4]{2y}$
- $\sqrt[3]{x^4} = x\sqrt[3]{x}$
- $\sqrt[4]{81} = 3$, $\sqrt[3]{8} = 2$
- $\sqrt{-x} \neq$ negative (undefined for real numbers when argument is negative)
- $\sqrt{x^2} = |x|$ (sqrt is never negative)
- Odd indexes: negative roots are OK
- $\sqrt[n]{x^n} = |x|$ if $n$ even; $= x$ if $n$ odd
- $\sqrt[4]{-16} =$ BAD (not real)

### Fractional Exponents

$$a^{m/n} = \left(\sqrt[n]{a}\right)^m = \sqrt[n]{a^m}$$

(Power on top, root on bottom)

- $4^{1/2} = \sqrt{4} = 2$
- $8^{2/3} = (\sqrt[3]{8})^2 = 2^2 = 4$
- $64^{3/2} = 8^3 = 512$
- $27^{-2/3} = \dfrac{1}{27^{2/3}} = \dfrac{1}{(\sqrt[3]{27})^2} = \dfrac{1}{9}$

### Radicals (add / multiply)

- $\sqrt{3} + \sqrt{3} = 2\sqrt{3}$
- $5\sqrt[3]{7} - 8\sqrt[3]{7} = -3\sqrt[3]{7}$
- Example combining cube roots: intermediate circled result $4\sqrt[3]{3} + 3\sqrt[3]{6}$
- $\sqrt{3} \cdot \sqrt{5} = \sqrt{15}$
- $3\sqrt{2} \cdot 2\sqrt{3} = 6\sqrt{6}$
- $\sqrt[4]{27} \cdot \sqrt[4]{3} = \sqrt[4]{81} = 3$

### Divide Radicals

*No radical in denominator.*

- $\dfrac{\sqrt{12}}{\sqrt{3}} = \sqrt{4} = 2$
- $\dfrac{12\sqrt{5}}{5\sqrt{3}} \cdot \dfrac{\sqrt{3}}{\sqrt{3}} = \dfrac{12\sqrt{15}}{15} = \dfrac{4\sqrt{15}}{5}$
- **Conjugate:** $\dfrac{2}{4+\sqrt{3}} \cdot \dfrac{4-\sqrt{3}}{4-\sqrt{3}} = \dfrac{8-2\sqrt{3}}{13}$
- $\dfrac{6}{\sqrt{5}+\sqrt{2}} \cdot \dfrac{\sqrt{5}-\sqrt{2}}{\sqrt{5}-\sqrt{2}} = 2\sqrt{5}-2\sqrt{2}$

## Page 2 — Rational Ops, Complex Fractions, Factoring, Domain

![Page 2](Ch.%20P_images/page-02.png)

### Rational Add / Sub

*Don’t CANCEL — factor before cancelling.*

- $\dfrac{3}{x+2} + \dfrac{4}{x+2} = \dfrac{7}{x+2}$
- $\dfrac{3}{x+2} + \dfrac{4}{x+1} = \dfrac{3(x+1)+4(x+2)}{(x+1)(x+2)} = \dfrac{7x+11}{(x+1)(x+2)}$
- Circled: $\dfrac{n^2-2n+15}{2n(n-3)}$
- $\dfrac{3}{x+2} - \dfrac{4}{x} = \dfrac{-x-8}{x(x+2)}$
- $\dfrac{2}{x(x+3)} + \dfrac{5}{(x+3)(x+6)} = \dfrac{7x+12}{x(x+3)(x+6)}$

### Complex Fractions (fractions inside a fraction)

- $\dfrac{\frac{2}{x}}{\frac{6}{x^3}} = \dfrac{2}{x} \cdot \dfrac{x^3}{6} = \dfrac{x^2}{3}$
- $\dfrac{\frac{x^2-1}{x}}{\frac{(x+1)^2}{2x}} = \dfrac{(x-1)(x+1)}{x} \cdot \dfrac{2x}{(x+1)^2} = \dfrac{2(x-1)}{x+1}$
- Example that simplifies to $x-8$

### Factoring Skills

1. GCF?
2. # of terms:
   - 2 terms → difference of squares or SOAP
   - 3 terms → leading coefficient no (easy) / yes (hard)
   - 4 terms → grouping

*“Factor completely” = GCF first, then factor.*

- $3x^2 - 3x - 36 = 3(x^2 - x - 12) = 3(x-4)(x+3)$
- $8x^5 - 12x^2 - 40x + 60 = 4(2x^5 - 3x^2 - 10x + 15) = 4(x^2-5)(2x-3)$

### Domain

Domain = $x$ values you can plug in.

**BAD:** $\dfrac{\text{any}}{0}$, $\sqrt{\text{neg}}$

| Example | Domain |
| :--- | :--- |
| $\dfrac{3}{x+4}$ | $x \neq -4$ |
| $y = \sqrt{x+6}$ | $[-6,\infty)$ |
| $y = \sqrt{3-5x}$ | $\left(-\infty,\dfrac{3}{5}\right]$ |
| $y = \dfrac{1}{\sqrt{3-5x}}$ | $\left(-\infty,\dfrac{3}{5}\right)$ |
| $y = \dfrac{4}{6+x}$ | $(-\infty,-6)\cup(-6,\infty)$ |
| $y = \dfrac{x+1}{x^2-3x-10}$ | $(-\infty,-2)\cup(-2,5)\cup(5,\infty)$ |

## Page 3 — Fractional Exponents, Polynomials, Factoring, Rational Stuff

![Page 3](Ch.%20P_images/page-03.png)

### Fractional Exponents

- $\left(x^{1/3}\right)^{-4/3} = x^{-4/9} = \dfrac{1}{x^{4/9}}$
- $\sqrt[3]{x^4} \cdot \sqrt[3]{x^2} = \sqrt[3]{x^6} = x^2$
- $\dfrac{1}{x^{1/2} \cdot x^{2/3}} = \dfrac{1}{x^{7/6}}$
- Circled rationalized forms such as $\dfrac{m^{11/9}}{n^{7/9}}$ and $\dfrac{m}{n^{1/4}}$

### Polynomials

| Expression | Type |
| :--- | :--- |
| $x^2+3x-4$ | Quadratic trinomial |
| $x^3+5x$ | Cubic binomial |
| $2x-3$ | Linear binomial |
| $-5x^4+3x^2-9x+1$ | Quartic polynomial |
| $y^5$ | Quintic monomial |
| $7$ | Constant monomial |

**Ops**

- $(2x^2-4x+7)+(x^2+5x-3)=3x^2+x+4$
- $(3x+2)(x+5)=3x^2+17x+10$
- $(2x-3)(x^2+5x-8)=2x^3+7x^2-31x+24$
- $(2x+5)^2=4x^2+20x+25$; compare $4x^2-25=(2x-5)(2x+5)$

### Factoring

**GCF / undistribute**

- $2x^4+6x=2x(x^3+3)$
- $-4x^5-8x^2+4x=-4x(x^4+2x-1)$

**Easy factoring** ($a=1$)

- $x^2+3x-10=(x+5)(x-2)$
- $x^2-5x+6=(x-2)(x-3)$
- $x^2+5xy+6y^2=(x+2y)(x+3y)$
- $x^2-6xy+9y^2=(x-3y)^2$

**Difference of squares**

- $x^2-16=(x+4)(x-4)$
- Note: **NO** sum of squares (e.g. $x^2+16$ stays prime over reals)

**Hard factoring (Voodoo / slide & divide)**

- $2x^2+5x-3 \rightarrow (x+3)(2x-1)$
- $6x^2-7x-3 \rightarrow (2x-3)(3x+1)$

**Sum / Diff of Cubes (SOAP)**

$$a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$$

SOAP = Same, Opposite, Always Positive

- $x^3-8=(x-2)(x^2+2x+4)$
- $27x^3+1=(3x+1)(9x^2-3x+1)$
- $64x^3-125=(4x-5)(16x^2+20x+25)$

**Grouping**

- $x^3-4x^2+3x-12=(x^2+3)(x-4)$
- $x^3+2x^2-9x-18=(x+3)(x-3)(x+2)$

**Quadratic form**

- $x^4-2x^2-24=(x^2-6)(x^2+4)$
- $6x^4+7x^2-20=(2x^2+5)(3x^2-4)$

### Rational Stuff

- $\dfrac{x^2-x-12}{x^2-9} \cdot \dfrac{x+4}{x-4} = \dfrac{x+4}{x-3}$
- $\dfrac{x^2+2x-15}{3x+3} \cdot \dfrac{2x}{x^2+7x+10} = \dfrac{2x(x-3)}{3(x+1)(x+2)}$
- $\dfrac{x^2-36}{3x} \div \dfrac{2x^2-12x}{4x^3+4x} = \dfrac{2(x+6)(x^2+1)}{3x}$
