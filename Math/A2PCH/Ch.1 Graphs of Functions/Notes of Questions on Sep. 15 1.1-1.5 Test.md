1. Write the equation for a circle with a tangent of -3 in relation to the x axis

   **Answer:** This question needs more information as written.

   If it means **a circle tangent to the x-axis with radius 3 and center below the x-axis**, then the center is `(0, -3)` and the radius is `3`:

   `(x - 0)^2 + (y - (-3))^2 = 3^2`

   `x^2 + (y + 3)^2 = 9`

   If it means **the circle is tangent to the x-axis at `x = -3`**, then there are many possible circles. The tangent point is `(-3, 0)`, so the center must be straight above or below that point:

   `(x + 3)^2 + (y - r)^2 = r^2`

   where `r` is the radius and `r ≠ 0`.

2. Check for symetry in y = (2(sqrt(x^2-2) + 6))/x^3

   **Answer:** The function has **origin symmetry**, so it is **odd**.

   Let `f(x) = 2(√(x^2 - 2) + 6) / x^3`.

   Replace `x` with `-x`:

   `f(-x) = 2(√((-x)^2 - 2) + 6) / (-x)^3`

   `f(-x) = 2(√(x^2 - 2) + 6) / -x^3`

   `f(-x) = -2(√(x^2 - 2) + 6) / x^3`

   `f(-x) = -f(x)`

   Since `f(-x) = -f(x)`, the graph is **odd** and has **origin symmetry**.
